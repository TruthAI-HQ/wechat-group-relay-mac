# 微信群聊同步助手（Mac）

在 Mac 上把指定源群的新增文字自动转发到多个目标群，也可以粘贴一次正文，手动发送给一份常用群名单。

## 首次安装并连接

1. 把腾讯下载的官网版微信安装到「应用程序」。如果机器已有微信，先确认聊天记录备份和当前版本，再更换客户端。登录后在「关于微信」确认版本为 **4.2.1.4（270596）**，然后按 **⌘Q** 完全退出微信。
2. 按插件作者的说明运行 2.16.0 的 PKG 安装包。该第三方插件会修改微信应用。完成后重开微信并登录。 [插件作者的安装说明](https://github.com/X1a0He/X1a0HeWeChatPlugin#如何安装)
3. 在微信顶部选 **X1a0He WeChat Plugin → MCP → 启用当前账号的 MCP**。打开同一菜单下的「MCP 状态」，确认连接已开启。
4. 解压助手 ZIP，打开 **群聊同步助手 1.5.2.app**。在助手点击 **MCP 连接**。默认配置可留空并点「保存并检查」。如果插件使用自定义设置，从微信插件的「关于 MCP」复制 HTTP JSON，粘贴到助手。助手只连接本机 HTTP 服务，凭据仅在本次运行中使用。

## 自动转发新增文字

1. 勾选「使用微信插件 MCP」。填入源群的完整名称，接着每行填一个目标群完整名称。点「检查当前源群」核对群名和读取。
2. 选择「简洁署名」或「详细引用」。默认只从源群发送到目标群。要让各群互通，勾选「目标群也作为源群」。
3. 第一次保持「允许向指定目标群实际发送」未勾选，点击「开始监听」。已有消息作为基线，启动后出现的新文字会在助手底部显示预览。需要实发时，点「停止」，核对目标名单，勾选实发，再点「开始监听」并确认。
4. 使用期间保持微信已登录、助手运行。需要停用时点「停止」。

**简洁署名**

```text
[小林@交流群 1]：今晚 8 点开始。
```

**详细署名**

```text
来自 交流群 1 的 小林 ：
--------------------------------
今晚 8 点开始。
```

插件提供可识别的引用信息时，详细格式可增加一个「回复」段落。图片、语音、文件、表情等非文字消息会跳过。

## 粘贴一次并群发

1. 每行填一个目标群完整名称。助手会保存这份名单。
2. 在「手动群发内容」中粘贴正文。实发开关关闭时，点击「手动群发」可预览。
3. 勾选实发后再点「手动群发」，核对确认框中的目标群名单，然后开始。
4. MCP 模式同一批的相邻提交至少间隔 5 秒。日志中的「已提交」表示插件接受了发送请求。最终消息以目标群聊天记录为准。

## 常见问题

- **找不到群或有同名群**。复制微信中的完整群名。遇到重名时，请使用区分开的群名再核对。
- **找不到 MCP 或微信打不开**。先核对微信来源、构建号和插件版本。恢复微信时使用腾讯原版 DMG 重新安装应用，保留微信数据目录。
- **窗口截图白屏**。已安装插件的 Apple 芯片 Mac 可以切到 MCP 模式。截图模式使用 macOS 的屏幕录制和辅助功能权限，需要助手里配置识别区域且保持微信窗口可见。
- **提交状态不明确**。助手会停止本轮。先在目标群核对；补发时仅选择尚未收到的群。
- **消息很密集**。监听器轮询近期消息。消息超过读取窗口时会重建基线，超出窗口的消息需要手动处理。

## 从源码构建

安装 Xcode Command Line Tools，在项目根目录运行以下命令。脚本编译 Apple 芯片和 Intel 两个架构，执行本地自测，并在指定目录生成 ZIP。

```bash
bash ./build.sh
```
