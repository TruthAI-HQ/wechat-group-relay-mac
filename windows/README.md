# 微信群聊同步助手（Windows）

选一个源群，自动监视窗口里出现的新文字，把它转发到填写的多个目标群。程序使用 Windows 屏幕截图、离线中文 OCR、画面比对和 Windows UI 自动化。无需微信插件。

```text
来自 直播交流群 的 小林 ：
--------------------------------
我们今晚八点开始。
```

## 下载与启动

1. 使用 Windows 10 或 11（x64），安装带 tkinter 的 **Python 3.12（64 位）**。 [Python 官方 Windows 下载页](https://www.python.org/downloads/windows/)
2. 安装并登录微信电脑版，将界面语言设为简体中文。 [微信官方下载](https://weixin.qq.com/)
3. 下载助手 ZIP 并解压到普通可写文件夹，双击 **start-windows.bat**。第一次运行会联网从 PyPI 安装依赖到包内的 `.venv`。之后可直接启动，聊天画面和 OCR 都在本机处理。 [下载 Windows 助手](https://github.com/TruthAI-HQ/wechat-group-relay-mac/blob/windows-relay/windows/WeChat-Group-Relay-Windows-1.0.zip)

## 验证并启动自动监视

1. 将微信主窗口打开并放大，保持聊天区可见。建议先使用默认的侧栏布局与 100% 显示缩放。手动打开源群，滚到会话底部，让窗口里至少有一条可识别的普通文字。
2. 在助手填入源群的完整名称。添加一个测试目标群，或用「批量导入」逐行粘贴多个不同的目标群全名。如果需要署名自己的消息，可填写「我的群昵称」。
3. 保持勾选「演练模式」，先点「截图并解析」核对群标题和正文，再点「开始监听」。第一张可识别画面用于建立基线。请在源群发一条新的普通文字，看助手是否显示完整转发预览。
4. 点击「停止」。演练正常后，取消「演练模式」，核对确认框中的目标群，点「开始监听」。再用一条普通文字验证测试目标群，确认后再扩大目标名单。
5. 自动监听时保持微信已登录、窗口在前台且无遮挡，避免手动切群、滚动源群或锁屏。发送时助手会短暂切到目标群，随后回到源群。点击「停止」可结束本轮。

## 设置与排查

- **标题校验失败**。确认群名能完整显示，标题带括号人数，群名在微信中唯一。尾部数字不同的群名会分开核对。
- **识别区偏移或画面空白**。调整助手的左、上、下边距，用「截图并解析」复查。微信版本、缩放及窗口布局会影响识别。
- **只能粘贴，没发出去**。把「发送键」设为微信当前使用的 `Enter` 或 `Ctrl+Enter`。开启前请检查各目标群输入框内已有的草稿。
- **日志显示已提交**。这表示助手已执行发送键，最终以目标群消息记录为准。发送状态不明时请先核对目标群。
- **画面里出现多条相同文字**。只要前后画面保留可匹配的消息，仍可同步新出现的那一条。消息滚出窗口、OCR 误识别或两帧无重叠时，可能漏转。
- **非文字消息**。图片、语音、文件、表情和引用的可识别占位会被过滤。OCR 根据画面判断消息类型，带清晰文字的图或文字卡片仍可能被误判。需要准确过滤时请先在演练中验证实际聊天布局。
